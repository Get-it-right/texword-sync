# 内容与修订边界

## 原生审阅

在 LaTeX 使用稳定且全文唯一的 ID；不跨次生成重新编号：

```latex
\twcomment[作者]{note-1}{原文锚点}{批注说明}
\twrevision[作者]{rev-1}{原文字句}{建议字句}{理由}
```

`twrevision` 是 Word 原生删除／插入；`twsuggest` 是旧式建议卡片，不能替代原生修订。ID 以英文字母起始，后续可含字母、数字、冒号、下划线和连字符。修订范围精确到实际变化词句，不把小改动扩大为整段修订。作者省略时为 Codex；特殊字符按 LaTeX 转义。

当前宏路径支持单个普通段落中的文字及行内 `cite`。原文空为纯插入，建议空为纯删除，两侧不得同时为空；公式、图片、跨段落、嵌套审阅和环境命令不放进宏范围。`ref`／`eqref` 等交叉引用保留在范围外。默认每组文献最多三个键；更大分组只在所用 profile 已明确支持时使用。

接受、拒绝、分侧处理或处理后继续编辑都回读用户实际决定。待定单侧插入可保留用户改写和引用，仍有删除侧的双侧待定范围内改写有保护限制。普通批注被删不代表采纳；“已解决”也不代表采纳。交错评论／修订、线程回复、跨段和富格式评论等受支持边界约束，失败时保留原件。

模板可加入普通 TeX 编译的兼容定义；它们显示原文而不显示建议，并非 Word 修订的执行逻辑：

```latex
\newcommand{\twcomment}[4][Codex]{#3}
\newcommand{\twsuggest}[5][Codex]{#3}
\newcommand{\twrevision}[5][Codex]{#3}
```

全文比较形成的原生修订使用独立 `native_comparison` 与调用方 `native_review` 配置，需要真实 Word CompareDocuments。不能假定宏范围支持全文复杂对象比较，也不为普通小改动自动启用该模式。

## 对象

- 公式生成可编辑 OMML，并按语义保留未变 TeX。新增和实际修改对象仍受 Pandoc 转换能力约束；不能从公式外观猜单位字体或任意归一化真实符号。
- cite/ref/eqref 生成 Word 原生域，图表与公式编号使用序列域。引用前后缀不在默认支持范围；用户修改参考文献尾部时不能直接被自动生成覆盖，应回到原 bibliography owner 处理。
- 普通表格、重复表头、列宽及部分合并单元格有既有实现。复杂表格导入受明确保护；合并表格编辑默认不启用，必须基于实际 profile 与 Pandoc 版本验证后配置。
- 图片保留原字节，支持受支持布局中的增删替换、尺寸和矩形裁剪映射；不擅自压缩、重采样或转码。复杂绘图、未知对象或布局不猜配。
- 封面／页尾的稳定范围、人工列宽及正文空段有专门保留路径，结构变化可能超出安全回读范围；按实际入口结果处置。

模板字体、标题、编号、图注前缀和 CSL 归源 adapter/profile；正文、术语及科学含义归调用者。不要把来源报告的中文标点、术语清单或学科规则写成通用引擎默认。

首次接入会区分有编号与无编号标题；原段落或样式继承链的 numPr 按保守编号证据处理。这不代表新增了任意自动编号渲染支持；没有可绑定的编号文字时仍可能安全拒绝，不能绕过原编号锚点检查。
